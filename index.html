While I sleep, sixteen agents ship my game.

The fleet runs overnight against Dungeon Heroes, the commercial Unity game I build. Its lanes are not guesses: a co-change analysis of the repository's history decides which files actually move together, so agents never collide. One serial lane owns the Unity scenes; four parallel worktrees carry everything else.

Every agent reports back in the same fixed contract: branch, files touched, what to verify, a confidence level, and anything it noticed outside its scope. Those findings become the next night's issues, so the fleet feeds itself work. Checks run cheapest first, and a single human gate survives, because what a screen looks like on a real device is information no pipeline holds.

Agents turn model spend into an operating cost, so I measured it like one and bent the curve: the expensive high-context share of the bill fell from 42.0% to 12.1%. And when I auditioned local models for the cheap end of the routing, I wrote them an eval with a hard 0.95 accuracy bar first. They scored 77.5% and 85.0%. They did not get the job.

The best delete of my career.

-162,256 lines, removed in one commit

Before the fleet there was a 35,000-line pipeline that turned written briefs into working Unity screens through typed contracts and five human gates. It shipped real screens into the game, and it priced its own work: $67 to $98 per accepted screen, with every rerun billed to whatever caused it.

Then its own telemetry delivered the verdict: the expensive validator half had zero confirmed true positives across 730 findings while carrying about half the spend. So it went, 1,240 files in one commit, and verification moved onto ground truth: the compiler, the filesystem, the live scene. The fleet is what took its place, and it ships more with a fraction of the machinery. Anyone can build a system. The job is reading the ledger honestly enough to unbuild one.

Stepland · Godot · one of three core programmers · live on both stores

The whole game runs on one number. It was failing.

Stepland turns real-world walking into a Tamagotchi-style pet, so every currency, streak, and reward sits downstream of one number: the steps the player took. That number arrived through a third-party health hub that could report connected while delivering zero. To a player, that is the game being broken at first launch.

I proposed reading the Android pedometer directly, then built the replacement in a week, in Kotlin, a language I had never written: the sensor reader, the background worker that keeps steps accruing with the app closed, the Godot to Android bridge. One permission prompt, no second-app setup, no silent zeroes. Stable ever since.

Same energy on deadlines: I rebuilt the tutorial as 82 declarative, resumable steps and landed it on the opening day of the 4YFN showcase, driving coding-agent sessions inside the production repository. And before any screen gets drawn, I block it out and the artist dresses it. The shipped game keeps my skeletons.

Dungeon Heroes · Unity · C# · solo

A full free-to-play game, built by one person.

The fight is what players see. What decides survival is everything they never notice, and those are the systems solo projects usually skip. I built them: damage resolves through an ordered stage pipeline, which is how 174 spells can reach into the same hit and the catalogue keeps growing, and the combat is tuned in tenths of a second, where every timing is an authored constant with a name.

Chest odds live in tables a designer wrote, with a pity floor you can reason about. Save files are versioned and migrated, never overwritten, and a migration that runs twice cannot pay its rewards twice. My favourite detail: the balance analyzer refuses runs recorded on my own dev machine, because the developer is the least representative player there is. The game does not trust me, by design.

Carried to signed Android release builds with the store compliance done, and built at fleet speed: the sixteen agents above write into this repository every night.

Purple Pwny · C# · Unity · 2023 to 2024

I gave the game a player. In 2024.

A roguelike's balance question is how an item performs in the hands of someone good, and no human plays ten thousand dungeons. So I wrote DunAI: 552 lines, delivered in one commit, a hand-authored decision agent that plays the dungeon crawler competently, so balance could be measured against skilled play instead of random rolls. Rules, not a learned policy, on purpose: when a number comes out strange, you read the file and see exactly why.

The same job shipped the Seashore biome, its boss, and about twenty relics designed from nothing but a name and an icon, plus a betting game whose race is computed backwards from a predetermined winner and still plays as a race. It is all playable in the browser.
